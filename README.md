# Clipchamp MCP Server

Model Context Protocol (MCP) server for automating Microsoft Clipchamp video editor operations.

## Features

- **`launch_clipchamp`**: Launch or attach to Clipchamp.
- **`create_new_video`**: Initialize a new project with custom aspect ratio.
- **`import_media`**: Import audio, video, and image assets.
- **`export_video`**: Export finished projects at specified quality levels.
